The transition test in script 73 compares a chain with enumeration in a reduced problem. Its results are distinct from the smoke test and full estimation runs.

Path resolution was checked by invoking commands from different working directories. The main command configures a UTF-8 locale before reading scripts. Python and R files also undergo syntax checks.

Package versions are recorded in [ambiente_testado.csv](ambiente_testado.csv). Python 3.10.7 was used with the versions in [requirements.txt](../requirements.txt).

It checked R syntax, input and result contracts, reconstruction of the 22 matrices, and reconstruction of Queen and Rook weights. The workflow pins that Ubuntu version.

These checks did not rerun full chains or reconstruct collection from administrative sources.
